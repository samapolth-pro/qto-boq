# QTO-BOQ

โปรแกรมถอดปริมาณจากแบบ (DWG / DXF / PDF / IFC) และจัดทำ BOQ เน้นงานระบบ (ไฟฟ้า สุขาภิบาล ดับเพลิง ปรับอากาศ)

- **ใช้งานผ่านเว็บ:** https://samapolth-pro.github.io/qto-boq/
- **ติดตั้งลงเครื่อง (Windows):** ดาวน์โหลด [download/QTO-BOQ.zip](download/QTO-BOQ.zip) แตกไฟล์ แล้วดับเบิลคลิก `Install-QTO-BOQ.cmd`
- **บัญชีราคากลาง:** [prices.json](prices.json) อัปเดตอัตโนมัติทุกสัปดาห์ โปรแกรมที่ติดตั้งในเครื่องจะดึงราคาล่าสุดจากไฟล์นี้ทุกครั้งที่เปิด (เมื่อต่อเน็ต)

แหล่งราคา: สนค. พาณิชย์จังหวัด, บัญชีราคา สพฐ., ราคาร้านค้า (ไม่รวม VAT) · ค่าแรง: กรมบัญชีกลาง ว480
